# Phase5 (カメラ最終接近) の仕組みと単体テストの使い方

対象: `main/main2.py` の Phase5、`sensor/goal_vision.py`、`test/test_phase5_live.py`

---

## 1. Phase5 は何をするフェーズか

Phase4 (GPS 誘導) でゴールから 2m 以内に来ると Phase5 に入ります。
GPS の誤差は数 m あるので、ここから先は **カメラで赤いゴール (カラーコーン) を見つけて近づき**、
最後に **超音波センサで「本当に 0m まで来たか」を確かめて** 終了します。

```
Phase4 (GPS) ─2m以内─▶ Phase5
                         │
                         ├─ カメラ起動 ─ 失敗 ─▶ 従来の超音波スキャン方式 (予備)
                         ▼
          ┌──▶ ① 止まる → ② 撮影 → ③ 赤を探す
          │         │
          │   見えない ─▶ その場で少し旋回して探す (1周しても無ければ少し前進)
          │   見える   ─▶ 赤が右にある → 右へ少し旋回 / 左 → 左へ / 正面 → 前進
          │   近い     ─▶ ④ 超音波で確認 (下の 3章)
          └──────────────────┘
```

### なぜ「止まってから撮る」のか (stop-and-go)
走りながら撮ると、画像がブレる・モータの振動で向きがずれる・判断が 1 テンポ遅れる、
といった問題が出ます。先輩のコード (cansat-system) と同じく
**1 回の動作を短いパルス (0.1〜0.8 秒) にして、止まるたびに撮り直す** 方式にしています。
遅くはなりますが、確実にゴールの方を向き直せます。

## 2. カメラでゴールを見つける仕組み (`sensor/goal_vision.py`)

1 枚の画像 (320×240) に対して次の処理をします。OpenCV 版で 1 枚約 24ms です。

| 手順 | やること | 目的 |
|---|---|---|
| 1. 縮小・ぼかし | 320×240 に縮めて軽くぼかす | 処理を速くし、細かいノイズを消す |
| 2. HSV 変換 | RGB を 色相(H)・彩度(S)・明るさ(V) に変換 | 「赤らしさ」を明るさと切り離して判定できる |
| 3. 色の判定 | H が 0〜12 か 165〜179 (赤)、S と V が一定以上、さらに R が G・B より十分大きい | 赤だけを白 (1) にした「マスク」を作る。茶色い土や肌色は除外 |
| 4. 明るさで閾値を調整 | 画面全体が明るい (晴天) と S・V の基準を下げ、暗いと上げる | 天気が変わっても検知できるように |
| 5. ノイズ除去 | オープン処理で点ノイズを消し、クローズ処理で割れた部分をつなぐ | コーンの白い反射帯で上下に割れても 1 つにする |
| 6. かたまりを数える | つながった白い領域 (連結成分) を大きい順に調べる | |
| 7. 形を確かめる | 縦長か / 下が広いか / 中まで塗りつぶされているか で「コーンらしさ」0〜1 を計算し、0.25 未満は無視 | 地面の赤い線・横長の赤い物・枠などを誤検知しない |
| 8. 結果 | 一番それらしい領域の **重心 x (0=左端〜1=右端)**、**面積比**、**画面端に触れているか** | |

- 近すぎる (面積 20% 以上)・画面端で切れている・小さすぎる (高さ 14px 未満) 領域は形が分からないので、形の確認はしません。
- 重心 x が 0.5 から **±0.10 以内なら「正面」**、それより右なら右へ、左なら左へ旋回します。ずれが大きいほど長く旋回します。
- 面積 20% 以上で「近い」、55% 以上 (または画面端に 2 辺以上触れて画面の 55% が赤) で「接触寸前」とみなします。
- OpenCV が使えないときは自動で numpy 版 (形の確認なし・1 枚約 80ms) に切り替わります。

## 3. 超音波で 0m を確かめる仕組み

カメラだけだと「大きく赤く写っている = 近い」としか分からず、本当に触れているかは分かりません。
そこで次のどれかになったら、**止まって超音波を 5 回測り**、その中央値で判断します。

- カメラで「接触寸前」
- ゴールが正面にあり、超音波が 0.40m 以下
- ゴールが正面で大きく写っているのに、超音波が測れない

| 判定 | 条件 | その後 |
|---|---|---|
| **CONFIRMED** | 中央値 ≤ 0.08m、ばらつき ≤ 0.05m、カメラでも近い | 0.3 秒押し込んで接触 → **もう一度超音波で確認** → OK なら **0m 到達** |
| **BLIND** | カメラは接触寸前なのに超音波が測れない (HC-SR04 は 2〜3cm 以下が測れない「不感帯」) | 0.25 秒下がって測り直す → 0.20m 以内に何かあれば「目の前にゴールあり」→ 押し込み → 確認 |
| FAR | 超音波ではまだ遠い | 前進を続ける (接触寸前なのに FAR が 5 回続いたら一度下がる) |
| OBSTACLE | 超音波は近いのにカメラ上のゴールは小さい | ゴールではない障害物 → 避ける |
| NOISY / SONAR_INVALID | 超音波がばらつく / 測れない | 判定せずに前進を続ける |

**0m 到達 (成功) になるのは、超音波で確認できたときだけ** です。超音波が壊れていると成功にはなりません (タイムアウトで終了)。

## 4. 単体テスト `test/test_phase5_live.py` の使い方

Phase0〜4 (落下検知・GPS など) を飛ばして、**Phase5 だけ** を実機で試すツールです。

### 4-1. 検知モード (既定) — モータは動きません

```bash
cd ~/TRC2027
python3 test/test_phase5_live.py              # カメラ + 超音波
python3 test/test_phase5_live.py --no-sonar   # カメラだけ (超音波を配線していないとき)
```

カメラの前で赤い物を左右に動かすと、Phase5 ならどう動くかが表示されます。止めるときは **Ctrl+C** です。

**コーンが手元にないとき** は、赤いコップ・箱・紙などで試せます。コーンらしい形でないと無視されるので、形状チェックを切ってください。

```bash
python3 test/test_phase5_live.py --no-shape --target-height 0.12   # 高さ 12cm の赤い物
```

### 4-2. 画面の見方

```
   T[s]  Det    Area     cx   Dir[°]  EstD[m]  Sonar[m]  Shape    ms  Position (L ←  → R)        Phase5の判断
   3.21    1   0.042   0.71    +13.9     1.85     1.920   0.81    24  ----------[-|---]-O-----  右へ旋回 0.15s
   3.55    1   0.045   0.52     +1.3     1.80     1.880   0.83    23  ----------[-|O--]-------  前進 0.80s
   9.10    1   0.610   0.50     +0.0      ---     0.060    ---    25  ----------[-|O--]-------  停止→超音波で0m確認 ⇒ CONFIRMED
```

| 列 | 意味 |
|---|---|
| T[s] | 開始からの秒数 |
| Det | 1 = ゴールが見えている |
| Area | ゴールが画面に占める割合 (0.20 以上で「近い」、0.55 以上で「接触寸前」) |
| cx | ゴールの重心の左右位置 (0 = 左端, 0.5 = 中央, 1 = 右端) |
| **Dir[°]** | **機体の正面から見たゴールの方向** (+ = 右, − = 左)。カメラの画角 62.2° から計算 |
| **EstD[m]** | **写り方から推定したゴールまでの距離** (`--target-height` の高さを使う。画面端で切れていると「---」) |
| Sonar[m] | 超音波の距離 |
| Shape | コーンらしさ 0〜1 (近い/小さい/画面端で切れているときは評価しない「---」) |
| ms | 1 枚の検知にかかった時間 |
| **Position** | **画面のどこにゴールがあるか**。`O` = ゴール, `\|` = 画面中央, `[ ]` = 正面とみなす範囲 |
| Phase5の判断 | 本番の Phase5 ならこの画像を見て次に何をするか (検知モードでは実際には動かない) |

`O` が `[ ]` の中にあれば前進、外にあればその向きへ旋回します。

この表とは別に、従来のフェーズと同じ形式のログが出ます。

- 3 秒ごとのまとめ: `[Phase5] ゴールの方向=右 13.9°  推定距離=1.85 m  超音波=1.920 m → Phase5の判断: 右へ旋回 0.15s`
- 見つけた・見失ったとき
- 超音波で確認したときの判定 (`[Phase5][GOAL確認] CONFIRMED: ...`)

### 4-3. 保存される画像

`test_images/phase5_live_日時/` に 3 秒ごと (と超音波確認のたび) に画像が保存されます。
**緑の枠 = 検知した領域、黄色の十字 = 重心** です。`--save-mask` を付けると、赤と判定した画素を白くした `_mask.png` も保存されます。
「何を赤だと思っているか」を確認するのに便利です。

### 4-4. 走行モード — ★モータが動きます★

```bash
python3 test/test_phase5_live.py --drive --timeout 60
```

`main2.py` の Phase5 (`phase5_camera_approach`) を **そのまま** 実行します。表示も本番と同じです。

- `yes` と入力すると 3 秒後に開始します。Ctrl+C で緊急停止します。
- 機体を床に置き、周りに人や物がないことを確認してから実行してください。
- GPS は動かしていないので、ログの GPS 距離は `nan` になります (Phase5 の動作には影響しません)。
- CSV ログは `logs/phase5_test_日時.csv`、画像は `logs/cam_日時/` に保存されます。

### 4-5. オプション一覧

| オプション | 説明 |
|---|---|
| `--no-sonar` | 超音波を使わない (検知モード) |
| `--no-shape` | 形の確認をしない (コーン以外の赤い物で試すとき) |
| `--target-height 0.12` | 距離推定に使うゴールの高さ [m] (既定 0.70 = コーン) |
| `--hue 0-20,165-179` | 赤と判定する色相の範囲を変える (オレンジ寄りのコーンなど) |
| `--rotate180` | カメラが上下逆に付いている |
| `--swap-rb` | 赤い物が青く (青い物が赤く) 判定される |
| `--backend numpy` | OpenCV を使わない版で試す |
| `--interval 0.3` | 撮影間隔 [s] |
| `--duration 30` | 30 秒で自動終了 |
| `--save-every 3` / `--save-max 50` / `--save-mask` | 画像保存の間隔・上限・マスク画像 |
| `--drive` / `--yes` / `--timeout 60` | 走行モード / 確認入力を省略 / タイムアウト秒 |

## 5. うまくいかないとき

| 症状 | 確認すること |
|---|---|
| 赤い物を写しても Det が 0 | `--save-mask` で白くなっているか確認。白くなっていない → 色が範囲外 (`--hue` を広げる)、暗すぎる (明るい場所で)。白いのに検知されない → 形状で落ちている (`--no-shape`) か小さすぎる |
| 青い物に反応する | 赤と青が入れ替わっている → `--swap-rb` (OK なら main2.py の `CAM_SWAP_RB = True`) |
| 右にある物で「左へ旋回」になる | カメラが上下逆 → `--rotate180` (OK なら `CAM_ROTATE_180 = True`) |
| 推定距離が実際と違う | `--target-height` が実物の高さと合っているか。画角が違う場合もある |
| 起動に何十秒もかかる | メモリ不足でスワップしている (Claude Code などを同時に動かしているとき)。本番では問題にならない |
| 「カメラを起動できません」 | 他のプログラム (rpicam-hello など) がカメラを使っていないか。`rpicam-hello --list-cameras` で認識されているか |

## 6. 調整する値 (main/main2.py の設定値セクション)

| 設定 | 既定 | 意味 |
|---|---|---|
| `CAM_HUE_RANGES` | (0,12),(165,179) | 赤とみなす色相 |
| `CAM_SHAPE_MIN_SCORE` | 0.25 | コーンらしさの下限 (本物を見落とすなら下げる。0 で無効) |
| `CAM_CENTER_TOL` | 0.10 | 正面とみなす範囲 |
| `CAM_NEAR_AREA_RATIO` / `CAM_CONTACT_AREA_RATIO` | 0.20 / 0.55 | 近い / 接触寸前 とみなす面積 |
| `CAM_TURN_*` / `CAM_FWD_*` | | 旋回・前進パルスの長さ (機体が動かなければ長くする) |
| `CAM_SEARCH_TURN_SEC` / `CAM_SEARCH_PULSES_PER_LAP` | 0.25 / 24 | 探索時の 1 回の旋回と、1 周あたりの回数 |
| `GOAL_CHECK_TRIGGER_DIST_M` | 0.40 | 超音波がこれ以下で確認に入る |
| `GOAL_SONAR_DIST_M` | 0.08 | **0m とみなす超音波の距離** (超音波の取り付け位置に合わせる) |
| `GOAL_BACKOFF_SEC` / `GOAL_FINAL_PUSH_SEC` | 0.25 / 0.30 | 不感帯対策で下がる時間 / 最後の押し込み時間 |
